# TITIK0 - APK
1. Buat repo GitHub baru, upload seluruh isi folder ini (tanpa node_modules), branch `main`.
2. Tab Actions > "Build APK" > Run workflow (atau otomatis saat push).
3. Setelah selesai, unduh artifact `TITIK0-apk` > `app-debug.apk`, pasang di HP Android
   (izinkan "pasang dari sumber tidak dikenal").
Ikon: assets/*.png (otomatis jadi ikon Android saat build).
Edit aplikasi di www/index.html. Jika menambah class Tailwind baru, jalankan `npm run css`.
